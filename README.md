# REPLAY

> 本地化沉浸式叙事创作与角色关系管理空间

---

## 产品定位

REPLAY 是一个为深度沉浸式创作者设计的**本地优先桌面应用**。

它是一个专门服务于「以角色为中心的长期叙事」的整理与创作空间。

**核心价值**：把碎片化的创作素材、记忆、角色关系，整合进一个有连续感、有归属感、完全私密的本地空间。

---

## 核心用户

| 用户类型 | 使用场景 |
|---------|---------|
| TRPG 玩家 | 管理角色历程、跑团记录、世界观设定 |
| 梦女 / 梦男 | 存储与 AI/虚构角色的互动记忆、情感连续性管理 |
| AI 角色扮演社群 | 多角色管理、剧情存档、设定维护 |
| OC 创作者 | 原创角色档案、世界构建、灵感收集 |
| 小说 / 游戏剧本写作者 | 角色关系图、剧情碎片整理、创作素材管理 |

**用户特征**：高度沉浸、角色驱动、情感连续性强。他们为「安全感」买单——不希望数据在云端漂浮，不希望创作记录因平台变动消失。

**真正解决的痛苦**：碎片化创作的焦虑——对话记录散落各处、角色设定随时间失真、灵感转瞬即逝，无处汇聚。

## 下载与安装

前往 **[Releases 页面](../../releases/latest)** 下载对应平台的安装包（当前 `v1.0.0-beta.3`）：

| 平台 | 文件 |
|------|------|
| macOS（Apple Silicon，M1 及以后） | `REPLAY-1.0.0-beta.3-mac.dmg`（或 `-mac.zip`） |
| Windows 64 位（安装版） | `REPLAY-1.0.0-beta.3-win.exe` |
| Windows 64 位（免安装） | `REPLAY-1.0.0-beta.3-portable.exe` |

> Intel Mac 暂未提供，需要请联系维护者。

### ⚠️ 升级前先备份数据

用过任何早期版本的用户，**升级前请完整复制一份你的 Vault 文件夹**（你当初选择的数据存储目录）。本版本含引用系统数据结构升级，首次打开旧 Vault 会自动迁移（有自动备份，但手动多备一份永远更稳）。全新用户跳过。

### macOS
1. 下载 `.dmg`，双击打开，把 REPLAY 拖进「应用程序」。
2. 首次打开会被系统拦截（「无法验证开发者」或「已损坏」）——**因为 beta 包未购买 Apple 签名，不是软件问题**：
   - **方式 A：** 在「应用程序」里**右键 REPLAY → 打开**，弹窗再点「打开」。只需一次。
   - **方式 B：** 若提示「已损坏」，终端执行 `xattr -cr /Applications/REPLAY.app` 后再双击。

### Windows
1. 下载安装版 `.exe` 或免安装 `portable.exe`。
2. 若出现蓝色 **SmartScreen** 警告：点「更多信息」→「仍要运行」。同样因 beta 阶段未购买代码签名证书，属正常。

## 首次启动

1. 界面默认**英文**，欢迎页右上角或设置里可切换 EN / 简体 / 繁体，选择会记住。
2. 启动后需**选择 Vault 目录**——你所有数据的存放位置，选一个你能找到的文件夹（**建议不要放在网盘同步目录**，beta 期间避免同步冲突）。
3. AI 功能需自备 API key（设置 → AI 配置）；不配置也能正常使用除 AI 外的全部功能。
4. 版本号在**设置面板底部**，反馈时请带上。
