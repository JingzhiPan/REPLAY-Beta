# REPLAY

> 本地化沉浸式叙事创作与角色关系管理空间

---

## 产品定位

REPLAY 是一个为深度沉浸式创作者设计的**本地优先桌面应用**。

它是一个专门服务于「以角色为中心的长期叙事」的整理与创作空间。

**核心价值**：把碎片化的创作素材、记忆、角色关系，整合进一个有连续感、有归属感、完全私密的本地空间。

---

## 核心用户

| 用户类型 | 使用场景 |
|---------|---------|
| TRPG 玩家 | 管理角色历程、跑团记录、世界观设定 |
| 梦女 / 梦男 | 存储与 AI/虚构角色的互动记忆、情感连续性管理 |
| AI 角色扮演社群 | 多角色管理、剧情存档、设定维护 |
| OC 创作者 | 原创角色档案、世界构建、灵感收集 |
| 小说 / 游戏剧本写作者 | 角色关系图、剧情碎片整理、创作素材管理 |

**用户特征**：高度沉浸、角色驱动、情感连续性强。他们为「安全感」买单——不希望数据在云端漂浮，不希望创作记录因平台变动消失。

**真正解决的痛苦**：碎片化创作的焦虑——对话记录散落各处、角色设定随时间失真、灵感转瞬即逝，无处汇聚。
